# Tardigrade-Dsup
hobby project on the tardigrade Dsup protein using Python and bioinformatics

**Status:** in progress

## Motivation
Tardigrades are micro-animals with the ability to survive extreme conditions such as radiation, desiccation and vacuum. The protein Dsup has been linked to protection of DNA against radiation damage and oxidative stress. This project explores the structure of the Dsup protein and it's purpose as well as how it differs between tardigrade species as way to practice python.
